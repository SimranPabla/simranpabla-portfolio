# Phase 1 Build Spec

## Audience and outcome

The primary audience is a recruiter scanning for 20–30 seconds. The homepage must establish Simranjit Singh as a University of Alberta Computing Science student whose base identity is software engineering and whose specialization is AI security and agent reliability.

## Routes

- `/` — recruiter-first overview
- `/work` — selected engineering work
- `/work/arc` — ARC case study
- `/work/cyberflow` — CyberFlow case study
- `/work/videogen` — VideoGen Pro case study
- `/work/packet-sniffer` — Packet Sniffer case study
- `/open-source` — upstream engineering contributions
- `/about` — background and education
- `/resume` — concise web resume
- `/contact` — public contact links

## Technical constraints

Astro static output, TypeScript, plain CSS, no backend, no client framework, minimal JavaScript, semantic HTML, visible keyboard focus, reduced-motion support, responsive single-column mobile layout, canonical URLs, sitemap, and robots.txt.

## Public-claim constraints

The public site may use GitHub-verifiable repository descriptions and local canonical ARC doctrine. Operator-reported CyberFlow scale metrics are not used in the Phase 1 headline or evidence cards. Academic and credential claims remain conservative until their private source records are rechecked for current publishability.
